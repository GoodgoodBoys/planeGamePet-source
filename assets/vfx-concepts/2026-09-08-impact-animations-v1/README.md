# 爱心碎裂与橙金 HIT! 动图预览

日期：2026-09-08。仅制作离线动图供确认，未接入游戏、更新 EXE 或操作服务器。

## 交付

- `heart-break-preview.gif`：蓝色与红色爱心并列；快速裂开、两半稍作停留、快速下落渐隐。
- `hit-orange-preview.gif`：原游戏状态栏位置示意与字样放大预览；放大、平行扫光、扫完后缩小、渐隐。
- 两份 GIF 均为 640 × 400，50 fps，100 帧，循环 2 秒。循环中的完整爱心和空槽停顿仅为反复观看；不是游戏内回血逻辑。

## 素材与制作方式

输入采用用户本轮提供并批准的两张关键帧图，逐字节复制为 `approved-heart-keyframes.png` 与 `approved-hit-keyframes.png`。原静态概念图来自前几轮内置 imagegen；本轮没有重新生成字形或逐帧重绘爱心，而是对已确认的位图做离线动画合成，使用已有项目同类预览的 System.Drawing + FFmpeg 流程，不使用 Python 或图像生成 API。

`PreviewAnimation.cs` 提取已确认爱心图中的原始爱心，并追踪第 04 帧的锯齿裂缝。按同一条分界线划分成两个互补、不可变的位图；所有分离/停留/下落帧仅改变这两张位图的位置和透明度。两半可逐像素还原完整素材，不会在后续帧变成平直切面。灰槽保持固定。

HIT! 使用已确认图中的字样作为同一母版，控制统一缩放和两道字面内平行反光，之后统一淡出。上方 HUD 只用于位置示意，来自之前保存的真实游戏截图；未运行或改变游戏本身。

## 当前节奏

### 爱心

| 相对动作开始 | 内容 |
| --- | --- |
| 0–120 ms | 裂纹从顶部中央向下贯穿 |
| 120–200 ms | 两半向左右各分开约 10 预览像素 |
| 200–500 ms | 对应第 05 帧，停留 300 ms，形状和透明度不变 |
| 500–760 ms | 加速下落、逐渐透明；断口和片块尺寸保持不变 |
| 760 ms 后 | 仅保留固定的灰色槽 |

循环前置完整爱心 300 ms，动作结束后保留空槽 940 ms，以便重复观看。

### HIT!

| 相对动作开始 | 内容 |
| --- | --- |
| 0–80 ms | 突然放大 |
| 80–360 ms | 两道平行亮带从左扫到右，期间不缩小 |
| 360–400 ms | 亮带完全扫完，短暂保持 |
| 400–480 ms | 轻微缩小 |
| 480–880 ms | 慢慢淡出 |

## 验证

- 合成器编译并执行成功。
- 对 21,874 个非透明源像素检查：左右片块无重叠、无丢失，重组后的颜色与完整原图一致。
- 第 05 帧停留段的第 25–40 帧 PNG 逐字节相同，不会发生停留抖动或断口变化。
- 两半自分离开始直到消失始终复用同一位图，不重新绘制。
- 绘制边界检查为 0 裁切。
- HIT! 扫光期间维持最大比例，扫完后才允许缩小。
- FFprobe 验证两份 GIF 均能解码到 100 帧、640 × 400、2.000 秒。
- 已从最终 GIF 解码关键帧进行画面复查，检查图为 `heart-gif-decoded-check.png`、`hit-gif-decoded-check.png`。

运行 `pwsh -NoProfile -File ./animate.ps1` 可重建本目录的预览输出。此脚本只处理本目录文件，不读取用户配对资料、不访问网络，也不改变游戏源代码。
