# Plane Pet：Windows 双人联网桌宠

## 当前发布基线：1.0.0（2026-09-09 重新编号）

按开发者要求，将原本地 1.0.3 候选的完整代码重新编号为 1.0.0，并以 1.0.1 验证同一正式通道的可选更新。这不是恢复早期 1.0.0 的旧代码。保留同排“开一局 + 四个表情”、整体向右追逐、280×150 窗口、损坏战绩保护、分代限量后台日志和可取消更新请求。构建输出 `dist/PlanePet-Release-Single-1.0.0.zip`。此前同名版本的 Git 提交和标签仅作历史归档，不强制改写；本次制品和发布状态见 `RELEASE-RESET-20260909.md`。

## 正式发布 1.0.0（2026-09-09）

本次从历史测试版 1.x / 2.x / 3.x 重新建立正式版 `1.0.0`，不是删除既有功能或回退同步机制。
正式版采用 `release_epoch=1` 和独立 OSS `plane-pet/windows/release/` 更新通道，仍使用完整的第三代确定性战斗同步。
测试者需先退出旧版，手动用正式包替换一次；不要删除 `%LOCALAPPDATA%\PlanePet`，绑定、设置、战绩保留。
旧测试版更新器不会自动降级到本版；双方都迁移后恢复联机对战。单机双端包只用于测试，不进入普通用户升级通道。

构建：`./build.ps1 -BuildPublic`。单端输出 `dist/PlanePet-Release-Single-1.0.0.zip`，其中 `PlanePet.exe` 内置联网组件、升级器、素材和许可文本。
当前发行按开发者决定未做 Windows 发布者签名；更新清单仍有独立 RSA 签名及 SHA-256 校验，二者不是同一回事。
迁移及验收记录见 `RELEASE-1.0.0.md`，后续运营/容量方案见 `RELEASE-1.0.0-OPERATIONS-PLAN.md`。

此目录只用于 Windows 桌宠双端测试，不替换也不删除原有的
ESP32 ↔ Windows 场景。它复用现有 `plane_link/shared` 的协议、竖屏世界和
游戏绘制规则，但使用独立端口、独立服务器、独立 EXE 和独立启动脚本。

## 当前已实现

- 3.0.4 将对战双翼拖尾收细为 1.5px 亮芯加 3px 淡外光（较 3.0.3 均缩窄 25%）。保留 1.05 秒持续时间、58px/s 后移速度、亮度与淡出曲线，继续沿实际移动轨迹弯曲，1 血时变淡；烟雾、命中、爆炸、窗口和同步规则不变。
- 同一台 Windows 电脑运行两个互相独立的桌宠实例。
- 任意六位匹配码都可作为一次性会合码；第一端等待、第二端同码即匹配。
- 主动停止匹配会发送取消并等待服务器确认；断网时保留取消记录，下次启动继续确认，完成前不能发起新匹配。未配对的等待记录在断线约 3 秒后清理；已撮合但尚未由双方保存确认的临时绑定在 60 秒后撤销，双方已确认的绑定不会过期。
- 同码记录匹配成功后立即消耗，后续设备可以重新使用相同数字。
- 匹配成功后保存永久绑定，后续启动自动恢复，不再要求输入匹配码。
- 离线时空闲桌宠显示单架蓝色动态飞机；好友在线时恢复原先红机在右前方、蓝机在左后方的追逐，
  两机整体向右，保留平滑转弯和间距变化；演示射击
  没有伤害或击落；在线绿点跟随红机，离线红点在蓝机附近；勿扰时显示月牙及边缘离线点。
- 鼠标移入桌宠时，底部同排显示静态 C 拳头“开一局”和右侧四个表情；均可直接点击。鼠标移出 0.4 秒后隐藏日常操作栏，再移入时全部显示。邀请卡片不受影响。窗口固定 280×150，表情按钮保持 35×33、图标保持 23×24。
- Idle 蓝机持续自动射击，沿用每 620 毫秒一发、子弹存活 1120 毫秒的节奏。每发子弹在发射时的机头左右各 15° 内随机偏转，随后保持直线；不造成伤害，不发送网络消息或统计事件。飞机保持原有飞行 / 跟随路线，真实对战射击规则不变。左键不控制射击，透明空白区恢复点击穿透；按住飞机仍可拖动桌宠。
- 提供 😂、😭、😡、勾手挑衅四个快捷表情；自己的气泡跟随蓝机，好友气泡
  跟随红机，服务器只转发固定表情类型并限制发送频率。
- 桌宠与游戏画面统一使用 D2 像素飞机；Idle 云层为同画风像素云。在线追逐已撤销绕圈和随机全方向两版实验逻辑。
- 匹配、空闲和邀请提示统一使用固定 `280×150` 悬浮窗；动画只在窗内绘制，
  状态卡片出现时不会改变悬浮窗的位置或大小。
- 右键飞机常态显示七项：邀请对战、历史战绩、暂停接收邀请、隐藏悬浮窗、设置与隐私、帮助与更新、退出。统计/数据/解绑收进“设置与隐私”，帮助/更新/诊断收进“帮助与更新”，最多两层，全部功能保留。托盘使用相同分组，隐藏后提供“显示悬浮窗”；游戏隐藏后显示“显示游戏窗口”。
- 未绑定时第一项为带勾选的“显示绑定电脑框”；搜索中另有“停止匹配”；已绑定但好友离线时，“邀请对战（对方离线）”置灰。菜单打开期间不重新排列，点击后仍校验实际状态。
- 可开启“暂停接收邀请”：蓝机出现黑底白月牙，不接收新邀请、不唤醒隐藏桌宠；仍可主动邀请和双向表情，设置按本机档案保存。
- 可从右键或托盘菜单导出匿名事件 CSV，或清除本机战绩和匿名实验事件；
  两种操作都不会影响永久绑定。
- 历史战绩窗口显示总局数、胜/负/平与胜率，并按本端视角保留最近 10 局的
  双方剩余生命和本地结束时间；关闭程序后仍会保留。
- 操作帮助默认显示简略页，右下角“详细帮助 →”进入完整说明；详细页左下角可返回。正文单独滚动，导航按钮固定在底部，切换不改变窗口大小和位置。
- 发出邀请后显示“等待对方响应...”、从 `300s` 到 `0s` 的剩余时间和可点击的“取消”按钮；最长等待 5 分钟。对方拒绝或超时后，原状态栏会保留 5 秒并显示具体结果。
- 收到邀请后显示“对方邀请你开一局...”，并提供绿色“接受”和红色“拒绝”按钮。
- 邀请卡片与按钮之间保留 10 像素边距；接收卡片为 `196×72`、等待卡片为 `244×56`，整体桌宠仍固定 `280×150`，不会因提示改变飞机位置。等待期间暂时收起不可发送的表情栏，回到空闲后恢复，避免卡片与表情重叠。
- 左键拖动飞机可改变悬浮窗位置。
- 第二个桌宠可从隐藏状态启动，收到邀请后自动弹出。
- 双方接受后，同一个进程从透明桌宠原位置展开为紧凑的 `240×372` 窗口；顶部
  `52px` 状态栏独立于下方游戏区域，不会遮挡飞机、子弹或星空画面；
  靠近屏幕边缘时自动调整位置，避免窗口超出桌面。
- 3 秒倒计时后开始游戏；任一方生命归零即结算，最长 3 分钟，超时则平局并计入战绩。
- 3.0.2 增加 A 款动态双翼拖尾、后向 ±15° 的分级受损烟雾、12 帧命中特效和 B 款战败爆炸。特效只读取对战呈现状态，不改变移动、碰撞、协议或统计；WIN!/LOST! 立即显示，爆炸独立播放 1.08 秒，提前返回会排队到动画结束。源码与素材说明见 `desktop/game_effects.h`、`assets/effects/README.md`；运行 `./verify_effects.ps1` 可检查真实绘制、资源透明度和结算返回流程。
- 飞机受到非致命命中时只扣除一格生命，保持当前飞行位置。
- 游戏结束后单击、按任意键或点击关闭按钮返回桌宠。
- 倒计时或对局中断线时不续接旧局：仍在线的一端显示“对方断线”，失去服务器连接的一端自动回到桌宠并显示“服务器连接中断，本局已结束”；服务恢复后仍保持桌宠状态。
- 客户端仅接受匹配服务地址、当前会话和递增序号的数据包；服务端会丢弃旧序号及重放动作。
- 客户端身份和服务端绑定库都使用原子写入与同版本备份；绑定无法持久化时不会宣告匹配成功。
- 托盘菜单支持显示、隐藏和退出。
- 桌宠透明区域允许鼠标穿透，不会遮挡下方窗口；飞机和当前消息卡片仍可点击。
- 桌宠进程启用 Per-Monitor DPI 感知，并使用适合透明窗口的灰阶字体抗锯齿，
  避免 Windows 在 125%/150% 缩放下把整个悬浮窗当作位图放大。
  桌宠保持 280×150、游戏内容区保持 240×372（HUD 52 + 地图 320）、更新卡保持 360×244 物理像素；内容与字体不随系统缩放变大。原生标题栏仍由 Windows 管理，帮助/历史沿用原有尺寸策略。
- 公网游戏隧道维持直连 ECS 的低延迟路径，不自动继承系统 HTTP 代理，也不修改系统代理设置；更新下载仍遵循系统代理。受限网络不保证可连接，不关闭 TLS 校验或改变组织网络策略。
- 键盘控制只在小游戏窗口位于前台时生效，切换到其他软件会立即停止键盘输入。
- 对局进行中按 `Esc`、关闭按钮或全局快捷键 `Ctrl+Shift+H` 可立即隐藏；托盘左键恢复。
- 首次运行会明确询问是否允许把匿名实验事件写入本地 CSV；事件包含应用版本、
  匿名邀请 ID 与对局 ID，便于正确计算响应率且避免把一次对局重复计数。

## 一键启动

```powershell
cd C:\Users\81228\Desktop\alive\ProjCode\V1_1PFIO\plane_link\pc_pet
.\run_local_dual.ps1
```

测试隐藏桌宠收到邀请后自动恢复：

```powershell
.\run_local_dual.ps1 -StartSecondHidden
```

默认配置：

- 本地服务器：`127.0.0.1:32110`
- 自动测试默认会合码：`123456`（服务器不预设固定匹配码）
- Alice：Player 1 / client 5101
- Bob：Player 2 / client 5102
- 对局时间：180 秒（`MatchSeconds=180`）

构建目录会生成本机演示用的 `PlanePetAlice.exe`、`PlanePetBob.exe`，以及两台电脑
通用的 `PlanePetClient.exe`。首次成功匹配后，
Alice、Bob 身份和绑定令牌分别保存在 `%LOCALAPPDATA%\PlanePet`，服务器的永久
绑定表也保存在该目录；关闭并重新启动后会直接恢复绑定。

也可以使用其他匹配码，或临时启用 5–180 秒的较短测试对局：

```powershell
.\run_local_dual.ps1 -Code 654321 -MatchSeconds 10
```

## 操作方式

- 未绑定：输入任意六位码并按 Enter，进入同码搜索。
- 搜索中：右键飞机或按 Esc 停止匹配并返回输入界面。
- 桌宠普通状态：鼠标移入桌宠，单击“开一局”；也可右键飞机选“邀请对战”。右侧四个表情直接点击发送，移出鼠标后整排操作按钮隐藏。
- 解除绑定：右键飞机或托盘图标选择“设置与隐私 → 解除绑定…”并确认；双方会回到匹配码输入页，本机历史战绩保留。
- 查看战绩或帮助：右键飞机（或托盘图标），选择“历史战绩”或“帮助与更新 → 操作帮助”；
  小窗口贴近桌宠打开，不会改变飞机悬浮窗的位置和大小。
- 暂停接收：右键勾选“暂停接收邀请”；再次点击恢复。好友在线绿点跟随红机，好友勿扰改为月牙；好友离线红点跟随蓝机，自己勿扰时红点贴月牙右下边缘。标记随各自表情框移动，悬停可看状态说明。
- 邀请勿扰好友：显示“对方已开启勿扰...”及 3 秒倒计时，可取消或 Esc 关闭；不创建真实邀请，表情照常可点。重复点击不延长提示；好友恢复后需重新邀请。
- 等待中接收方开启勿扰会结束该邀请；发起方开启勿扰不取消自己发出的邀请。服务器已进入倒数/游戏后，不因勿扰切换而中断。
- 完整状态同步和专用反馈需要 1.0.4 客户端及配套服务端。旧客户端保留原有数据包，可能仅显示拒绝；状态未知不推断为关闭。重连重新同步，勿扰同步不受匿名统计授权影响。
- 清除数据：右键选择“设置与隐私 → 清除本地战绩与统计…”，确认后删除本机战绩和实验事件，保留绑定与设置，不清除服务器记录。
- 导出数据：右键选择“设置与隐私 → 导出统计记录…”，将当前客户端的匿名事件另存为 CSV（不是导出绑定或完整战绩）。
- 收到邀请：左键点击绿色“接受”或红色“拒绝”按钮。
- 已发出邀请：左键点击“取消”按钮。
- 移动桌宠：待机时按住飞机左键拖动；初次绑定或搜索匹配时，也可按住匹配码输入框或信息卡拖动。
- 未绑定显示：绑定电脑框首次默认打开；右键取消勾选“显示绑定电脑框”后可只看飞行动画，此偏好会保留到下次启动。
- 游戏中：WASD 或方向键移动。
- 游戏中也可在画面内按住鼠标左键拖动飞机，松开即停止跟随。
- 桌宠与对局飞机使用同一套 D2 像素机型；对局碰撞盒和移动范围不变，己方/对方
  子弹使用带深色描边、明亮弹芯和短尾焰的像素弹体，己方为高亮青蓝色、对方为
  洋红色；Idle 追击子弹为暖黄色。子弹碰撞范围、射速和伤害保持不变。
- 游戏顶部 HUD 使用经典布局：左侧蓝色己方飞机与蓝色像素爱心，右侧红色对方飞机与红色像素爱心；每方固定三格，已扣除的血量显示同形状灰色心槽，与历史战绩采用同组素材。中间显示剩余时间，下方显示网络延迟。
- 游戏结束：单击、按任意键或点击关闭按钮返回桌宠。
- 紧急隐藏：对局进行中按 Esc、关闭按钮或 `Ctrl+Shift+H`；隐藏不记录键鼠内容，也不会强制中断正在进行的对局。
- 托盘左键：恢复桌宠。
- 托盘右键：显示、隐藏、查看战绩、打开帮助或退出。

## 自动验收

`PlanePetIntegrationTest.exe` 验证两个真实 UDP 客户端完成临时码匹配、上线、
邀请、旧动作重放拦截、取消、再次邀请、接受、倒计时、超时平局和返回流程。
`PlanePetPairingLifecycleTest.exe` 覆盖主动取消、断线淘汰、匹配码复用、两组同时
绑定、服务器重启后的永久绑定恢复、解除绑定以及重新绑定。`verify_gui_flow.ps1` 则验证首次匹配、隐藏端
邀请唤醒和第二次启动免匹配：

```powershell
.\verify_gui_flow.ps1
```

`--auto-invite` 和 `--auto-accept` 只用于此自动验收，正常启动脚本不会使用。

`verify_pet_interactions.ps1` 还覆盖固定悬浮窗、鼠标命中、邀请取消/拒绝/接受、
勿扰自动拒绝、紧急隐藏、DPI 信息窗口和战绩持久化；
`verify_restart_regressions.ps1` 专门验证客户端崩溃重启不会恢复旧对局或重复记战绩；
`verify_invite_timeout.ps1` 验证超时提示、回到 idle 和不生成错误战绩。所有脚本默认
自动选择临时 UDP 端口，因此不会连接到正在使用的桌宠服务。

`verify_update_windows.ps1` 编译专用的更新状态与窗口回归程序，覆盖所有更新
状态的关闭、迟到响应、取消下载、连续检查、7 天免提醒、大版本兼容提示，
以及邀请/对局期间延后提示和安装。测试使用独立临时存档及本地模拟完成信号，
不向公网发送请求，也不会安装更新；测试接口不会编译进发布程序。

## 本地实验数据

用户同意后，客户端在绑定存档旁创建 `<客户端>.events.csv`，字段为时间戳、匿名随机
`client_id`、应用版本、匿名邀请 ID、匿名对局 ID、事件名和数值。它不会记录匹配码、
聊天文字、按键、鼠标轨迹、屏幕内容、窗口标题或其他应用信息；快捷表情只记录
四种固定类型的发送/接收事件。普通本地/LAN 构建不会上传；
公网构建会另行明确询问是否发送匿名统计，只有同意后才会上传。启动客户端时
传入 `--telemetry=0` 可完全关闭；
传入 `--events=<路径>` 可指定输出文件。建议真实测试前向参与者说明用途并取得同意。

每个客户端还会在绑定存档旁创建同名 `.history` 文件。文件仅保存总胜负统计和
最近 10 局的结束时间、自己剩余生命、对方剩余生命及胜负结果；不包含匹配码，
也不会自动上传。战绩按本端视角独立记录，因此同一局在双方电脑上分别显示自己的
剩余生命与结果。

## 双击体验版

构建后直接双击 `dist\PlanePetFullFlow.exe`。这是单文件体验版，内置本地服务器和
两个客户端，不需要把旁边的其他 EXE 一起复制。首次启动时，Alice/Bob 都停留在
空白匹配码页面；在两端输入任意相同的六位码并按 Enter，即可从绑定、上线、
邀请、接受到最长 3 分钟的游戏完整体验。再次双击时会自动恢复永久绑定。退出两个桌宠后，
启动器会一并关闭它创建的本地服务。

`dist\PlanePet-LAN.zip` 是两台电脑局域网测试包；`dist\SHA256SUMS.txt` 提供单文件、
通用客户端、服务器和测试包的 SHA-256 校验值。

直接发送给普通体验测试者时，使用 `dist\PlanePet-Tester.zip`。测试者解压后只需
双击根目录的 `PlanePet.exe`，程序会自动启动一台电脑上的两个桌宠和内置本地服务；
无需安装、联网或配置服务器。

## 两台真实 Windows 电脑

局域网测试时，选择一台电脑运行服务。先生成一条仅本次测试人员知道的 128 位密钥：

```powershell
$bytes = [byte[]]::new(16)
[Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
$key = [Convert]::ToHexString($bytes).ToLower()
$key
.\run_network_server.ps1 -NetworkKey $key -SkipBuild
```

如 Windows 防火墙阻止访问，需要由测试者明确允许 `PlanePetServer.exe` 的 UDP
`32110` 入站连接。两个客户端分别在自己的电脑运行，`192.168.1.20` 替换为服务端
电脑的实际局域网 IPv4，密钥使用上一步生成的同一值：

```powershell
.\run_single_client.ps1 -Server 192.168.1.20:32110 -NetworkKey $key -Name Me -PeerName Friend -SkipBuild
```

客户端身份由程序首次启动时安全生成并写入各自存档；脚本不会在下次启动时换掉身份，
因此匹配成功后仍会自动恢复永久绑定。同一台电脑模拟两个网络客户端时，需为两次启动
显式提供不同的 `-State` 路径。

网络协议会对控制、输入和快照包做带密钥的完整性鉴权，服务端还限制配对请求速率、
等待队列大小，并拒绝没有密钥的非回环监听。它目前不加密游戏流量，也没有账号、密钥
轮换、NAT 穿透或抗大规模 UDP 攻击能力。因此可用于受控局域网，或经由可信 VPN 进行
异地小规模测试；不要直接把 UDP 端口暴露到公网。正式公网测试仍需部署带传输加密、
账号鉴权、密钥轮换、日志监控和限流的长期在线服务。

## 两台电脑公网测试版

`dist\PlanePet-Public-Single-1.0.2.zip` 是两台不同 Windows 电脑使用的免配置单端测试包。
两位测试者分别解压并双击其中的 `PlanePet.exe`，程序会在后台启动本机 UDP→WSS
隧道并连接：

- `wss://8.166.124.212:32112/v1/tunnel`
- ECS 内部桌宠服务：`127.0.0.1:32110/UDP`
- TLS 入口：`32112/TCP`，Let's Encrypt 公网 IP 证书自动续期

广州地域 ECS 会重置未备案域名的公网 TLS SNI，因此测试版直接连接公网 IP。该入口
使用 Let’s Encrypt 为 `8.166.124.212` 签发的受信任 IP 地址证书，Windows 仍执行完整
证书校验，不关闭主机名或 CA 校验。IP 证书约 6 天有效，服务器使用独立 Certbot 5
计时器每 6 小时统一检查 IP 与旧域名证书续期，并在续期成功后自动重载 Nginx；系统
自带的旧 Certbot 1.21 计时器已停用，以免读取新版 IP 证书配置或争抢续期锁。

公网入口不会共享或在 EXE 中嵌入全局服务器密钥。每台电脑首次启动时使用系统安全
随机数生成独立 256 位凭据，由 Windows DPAPI 加密保存在
`%LOCALAPPDATA%\PlanePet\tunnel.credential`；服务器只保存 SHA-256 哈希、登记时间
和用于限流的不可逆来源分组值，不持久保存原始来源 IP。未知安装凭据受每个来源和
服务器总量限制，可单独撤销。

公网构建在首次运行时单独询问是否允许发送匿名测试统计。仅在用户同意后，客户端才会
通过同一条 TLS/WSS 加密隧道发送启动/退出、60 秒会话心跳、匹配和好友在线状态变化、
邀请响应、桌宠显示/隐藏与勿扰状态、快捷表情固定类型，以及对局过程和结果。网关从随机安装凭据的哈希派生匿名安装
标识，不采集聊天文字、匹配码、姓名、键鼠轨迹、屏幕内容或窗口标题。原始事件保存在 ECS 的 SQLite 数据库中，默认保留
90 天，由独立线程每分钟清理，后台汇总前也检查过期；统计拥堵时允许丢弃事件，不阻塞游戏。使用时长仅累计开启统计期间；旧客户端按可观测事件间隔保守计时。右键“设置与隐私 → 匿名使用统计”可随时停止后续记录。管理员统计页使用独立强密码的
HTTP Basic 鉴权，不复用客户端凭据。

ECS 使用独立的 `plane-pet.service`、`plane-pet-gateway.service` 和 Nginx WSS
入口；原 `plane-link.service` 与 `32100/UDP` 不被替换。公网桌宠 UDP 服务和网关只
监听回环地址，外部不能直接访问 32110/32111。

真实 TLS 冒烟测试脚本为 `tests\public_gateway_smoke.py`；它验证受信任证书、WebSocket
升级、独立凭据登记以及一次匹配等待包的 UDP 往返，不创建永久绑定。服务器上的测试
凭据应在验收后清除，正式客户端会在首次连接时自行登记。

本场景端口 `32110` 与原 ESP32 ↔ Windows 场景的 `32100` 分离，未删除或替换任何
设备互通代码。

### 单机双端公网验收包

`dist\PlanePet-Public-DualLocal-1.0.2.zip` 用于只使用一台 Windows 电脑验证完整公网流程。
其中的单文件启动器会启动两个独立桌宠和两条 WSS 隧道：A 端使用本机 UDP `32110`，
B 端使用 `32113`；两端拥有不同的设备身份、DPAPI 凭据、绑定存档、设置、战绩和
实验事件文件，但都会连接同一个 ECS 公网入口。它不会启动或绕回本地游戏服务器。

两个桌宠输入相同六位码即可验证公网匹配、在线状态、邀请、接受、对局和退出；匹配
成功后关闭两端并重新启动，还可验证永久绑定恢复。此模式能验证真实 TLS/WSS 与 ECS
服务逻辑，但两端仍共享一台电脑的系统时钟、网络栈和公网出口，不能替代两条独立网络
环境下的最终测试。不要同时运行普通公网包，否则 `32110` 可能发生本地端口冲突。
