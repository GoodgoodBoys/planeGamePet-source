# W1 / L1 结算素材

用户选定 W1 动态 WIN! 与 L1 静态 LOST!，于 3.0.7 接入 Windows 桌面客户端。

## 来源与导入

- 已批准原稿和动画：`../vfx-concepts/2026-09-08-win-w1-v1/`。
- `prepare_result_titles.ps1` 将已批准的 120 张透明 W1 帧等比缩小一半并排列为图集，不重新绘制字形或扫光。
- L1 从 `approved-lost-options.png` 第一列大字精确截取并去除深蓝背景；原始抠图保存为 `lost-l1-master.png`，不添加动画或重新着色。
- `win-w1-120.png`：1920×960 RGBA，10 列 × 12 行，每帧 192×80；资源 ID 179。
- `lost-l1.png`：192×80 RGBA，文字宽 150 像素，透明居中；资源 ID 180。

## 动画

- 50 fps、120 帧、2.4 秒循环。
- 0–180 ms：100% 放大至 112%。
- 180–700 ms：从左至右扫光；沿用已批准的宽亮带（主、伴亮带各为原 HIT 的两倍宽）。
- 700–900 ms：缩回原尺寸。
- 900–2400 ms：停留后再次循环；停留帧及首尾像素一致。
- LOST 全程只画同一张静态素材。

## 运行约束

图集只加载一次，按帧取源矩形，使用最近邻缩放。位置为游戏地图坐标 (24, 100)，尺寸 192×80；不改变 240×372 逻辑窗口及独立 HUD。

时间轴只决定绘制，不改变胜负、血量、碰撞、服务器同步或战绩统计。新局重置；重复结算消息不重启动画；对方先返回时保留原结算时间轴。无限循环不延长现有终局爆炸的返回等待。

平局和同步中止继续使用原中文说明。缺失或尺寸错误的素材回退为原文字标题。

回归入口：`verify_effects.ps1`、`tests/verify_embedded_components.ps1 -Version 3.0.7`。
